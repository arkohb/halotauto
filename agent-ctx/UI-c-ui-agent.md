# UI-c · Visual-only refactor record (9 HALO components)

Agent: UI-c (visual/honest-state pass)
Scope: ONLY the 9 assigned files. No fetch URL/interval/handler/flow/export/aria-label/copy changes anywhere.

## Shared conventions used
- Static colors → inline `style` via `C.*` / `A.*` tokens (ui-helpers).
- Hover-bearing controls KEEP their Tailwind arbitrary classes: an inline base color would override Tailwind `hover:*` states (inline > class specificity). Every such literal maps 1:1 to a C token (e.g. `#E3C25A` = `C.goldHover`).
- Translucents of colors with no `A` accessor (muted `#8C98AE`, navy `#0B1426`, line `#1C2A47`) stay as rgba literals of the exact token values — `A` only covers gold/cyan/teal/ice/green/red/warn/white.
